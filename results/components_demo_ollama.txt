[3] Chain — 여러 작업을 순차적으로 연결
======================================================================
chain = prompt | model | StrOutputParser()
결과: 프롬프트 인젝션은 프로그래밍 언어에서 프롬프트를 사용하여 코드를 inject하는 기술입니다. 프롬프트는 사용자에게 코드를 입력하도록 요청하는 문구입니다. 프롬프트 인젝션은 사용자가 코드를 입력할 때, 코드가 실제로 사용자에게 입력되는지 확인하기 위해 사용됩니다.

======================================================================
[5] Vector Store — 임베딩 벡터 데이터 저장
======================================================================
문서 3개를 벡터로 바꿔 저장했습니다.
예) '환불은 구매 후 7일...' 의 벡터: [0.5, 0.0, 0.0, 0.0, 0.5, 0.5, 0.5, 0.0, 0.0, 0.0]

======================================================================
[4] Retriever — 문서 및 데이터 검색
======================================================================
질문: 환불은 며칠 안에 해야 하나요?
검색된 문서: 환불은 구매 후 7일 이내에 주문 취소 메뉴에서 신청할 수 있습니다.  (source=policy-refund)
RAG 체인 답: 환불은 구매 후 7일 이내에 주문 취소 메뉴에서 신청할 수 있습니다.

======================================================================
[7] Tools — 검색, API, DB 등 외부 기능 연결
======================================================================
도구 이름: lookup_order / 설명: 주문 번호로 배송 상태를 조회한다. / 인자: ['order_id']
도구 이름: add / 설명: 두 정수를 더한다. / 인자: ['a', 'b']
직접 호출 lookup_order('A100') → 배송 중 (도착 예정 2일 후)

======================================================================
[6] Agent — 상황에 따라 도구를 선택하고 실행
======================================================================
모델이 선택한 도구: lookup_order({'order_id': 'A100'})
도구 실행 결과: 배송 중 (도착 예정 2일 후)
최종 답: {"name": "update_order_status", "parameters": {"order_id": "A100", "status": "shipping"}}
